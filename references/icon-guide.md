# Picking Meaningful Icons

The whole point of this skill is that the icon helps recall the keyword.
A generic or arbitrary icon (e.g. a random gear on everything) defeats the
purpose. For each node that gets an icon, run this reasoning:

1. **Is the keyword already a concrete thing?** ("Book", "Handshake",
   "Brain") → use its literal icon.
2. **If it's abstract, what's the closest physical metaphor?** Ask: what
   object, body part, action, or widely-understood symbol do people already
   associate with this idea?
   - Growth / improvement → a plant, an upward chart, a rising arrow
   - Risk / caution → a warning triangle, a shield
   - Communication / social → people, speech bubble, handshake
   - Time / pace → clock, hourglass, stopwatch
   - Structure / organization → a checklist, blocks, a blueprint
   - Emotion → a face expressing it, a heart, a brain
   - Direction / decision → a compass, a signpost, a fork
3. **Prefer specific over generic.** "Curiosity" → a magnifying glass beats
   a generic star. "Discipline" → a clipboard-check or lock beats a gear.
4. **Sanity-check uniqueness.** If two sibling branches end up with the same
   or visually-similar icon, at least one of your choices was too generic —
   go back and find something more specific to that keyword.

Only use FontAwesome 6 **solid** (free) icons, referenced as `fa fa-<name>`
(the shorthand alias form used throughout this vault's existing mindmaps).
Do not use `fa-brands` (logos) or any icon that requires a Pro subscription
— those won't render with the free CDN link in the template.

## Cheat sheet: concept → icon class

Use these as starting points, not a closed list — FontAwesome has ~2000
free solid icons; search https://fontawesome.com/search?o=r&s=solid&f=classic
when a concept isn't below.

| Concept | Icon class |
|---|---|
| Brain / mind / cognition | `fa-brain` |
| Growth / progress | `fa-seedling`, `fa-arrow-trend-up` |
| Curiosity / exploration | `fa-magnifying-glass`, `fa-compass` |
| Creativity / imagination | `fa-palette`, `fa-lightbulb` |
| Discipline / structure | `fa-clipboard-check`, `fa-ruler` |
| Goal / target | `fa-bullseye`, `fa-flag-checkered` |
| Social / people | `fa-people-group`, `fa-handshake` |
| Communication | `fa-comments`, `fa-message` |
| Emotion / feelings | `fa-face-smile`, `fa-heart`, `fa-heart-crack` |
| Trust / cooperation | `fa-handshake`, `fa-people-arrows` |
| Competition / conflict | `fa-chess-knight`, `fa-fist-raised` |
| Anxiety / stress | `fa-bolt`, `fa-triangle-exclamation` |
| Calm / resilience | `fa-spa`, `fa-shield-heart` |
| Time / schedule | `fa-clock`, `fa-hourglass-half` |
| Habit / routine | `fa-repeat`, `fa-calendar-check` |
| Risk / caution | `fa-triangle-exclamation`, `fa-shield` |
| Energy / activity | `fa-bolt`, `fa-fire` |
| Rest / recovery | `fa-bed`, `fa-battery-full` |
| Ranking / scoring / scale | `fa-ranking-star`, `fa-gauge` |
| High / more / increase | `fa-plus`, `fa-arrow-up` |
| Low / less / decrease | `fa-minus`, `fa-arrow-down` |
| Code / logic | `fa-code`, `fa-diagram-project` |
| Money / value | `fa-coins`, `fa-sack-dollar` |
| Health / body | `fa-heart-pulse`, `fa-dumbbell` |
| Decision / choice | `fa-code-fork`, `fa-signs-post` |
| Learning / study | `fa-book-open`, `fa-graduation-cap` |
